# ChaiVerse - Product Landing Page

A modern, responsive product landing page for a premium chai brand, built with HTML, CSS, and vanilla JavaScript. This project demonstrates clean UI design, responsive layout techniques, and smooth user interactions.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that adapts to mobile, tablet, and desktop screens using Flexbox.
- **Modern UI**: Clean typography, consistent color palette, and visual hierarchy.
- **Interactive Elements**:
  - Smooth scrolling navigation.
  - Hover effects on feature cards and pricing plans.
  - Custom preloader animation.
- **Scroll Animations**: Elements fade in and slide up as they enter the viewport using the Intersection Observer API.
- **Semantic HTML**: Built with accessibility and SEO in mind.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Flexbox, CSS Variables, Gradients, Transitions, and Keyframe Animations.
- **JavaScript**: DOM manipulation, Intersection Observer for scroll animations, and preloader logic.
